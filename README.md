# 天下策 | Tianxia-Ce

一款免安裝、無建置流程的瀏覽器策略遊戲原型，使用原生 HTML、CSS、JavaScript 與 Canvas 2D。

## 開始遊玩
直接開啟 `index.html`。若要公開成網站，進入 GitHub 專案的 **Settings → Pages**，選擇 **Deploy from a branch**、分支 `main`、資料夾 `/ (root))，儲存後等待 GitHub Pages 部署完成。

## 目前可玩內容
- 簡單、普通、困難、流亡四種開局；可切換 AI 自主外交與戰爭、戰爭迷霧。
- Canvas 戰略地圖、城池選取、勢力與道路。
- 日/月推進、暫停、不同模擬速度。
- 城池農田、商市、城防、賑濟等政務。
- 糧食、錢帛、軍隊、民心、城防等資源與數值。
- 招募人才、徵兵、屯田、推動新政。
- 派遣使者、商貿、同盟與宣戰。
- 簡化戰鬥：正面強攻、迂迴側擊、堅守、撤退；戰鬥期間戰略時間停止。
- 本機瀏覽器存檔與讀檔。

## 原型範圍
這是可操作的早期原型，不是完整最終版。更完整的圍城階段、多部隊戰術操作、將領生涯與家族傳承、細緻情報迷霧、補給線及更深入的 AI 決策，仍待後續開發。

## 存檔
存檔保存在目前瀏覽器的 `localStorage`，不會自動同步至其他裝置。
